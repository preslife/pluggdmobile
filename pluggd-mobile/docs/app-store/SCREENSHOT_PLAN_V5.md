# Build 5 App Store Screenshot Plan

Use only final Build 5 screens containing rights-cleared PLUGGD or
creator-authorized media. Capture matched portrait screenshots from the final
Release build and do not place phone frames, illegible captions or unrelated
marketing artwork over the UI.

1. Home — immediate playable release and four choices.
2. Carnival — native hero plus four discovery gateways.
3. Discover — actionable exploration and clear discovery reasons.
4. Live — active room with fixed-price gift tray.
5. Community — stories, current feed and visible create action.
6. Events — featured Carnival guide and event discovery.

Required checks for every image:

- [ ] Actual Build 5 interface; no mockups or login/splash-only screens.
- [ ] Correct device dimensions, portrait orientation and no alpha channel.
- [ ] Status bar, safe areas, dock and mini-player are visually clean.
- [ ] All text is legible at App Store thumbnail size.
- [ ] No private email, payment detail, test label, debug copy or fabricated activity.
- [ ] Every visible artwork/avatar/event image is present in the rights register.
- [ ] The five IAP review screenshots match their exact product; optional promotional IAP images remain empty.
