# Build 8 App Store Screenshot Plan

Capture the actual final Build 8 interface from the release candidate. Use only
PLUGGD-owned or explicitly creator/partner-authorized media that is cleared in
`CONTENT_RIGHTS_REGISTER.md` for both product and App Store marketing use.

## Priority public set

1. Home — immediate music value and polished native discovery.
2. Discover — Listening Floor, Mixes, BeatPlug and PLUGGD DJ destinations.
3. Listening Room — portrait vinyl deck, real controls and current mix context.
4. Community — stories-first feed and five-part internal dock.
5. Live — fan view with creator identity, comments and bottom interactions.
6. Creator Studio — native creator workspace and useful catalogue actions.
7. Events — current event discovery and the populated map.
8. BeatPlug — featured audition, search and Beat Bench flow.
9. Store — creator goods/physical commerce with no misleading digital CTA.
10. Profile — creator catalogue and membership value, only if identity/media clearance is complete.

Use the strongest rights-cleared six to ten images. Do not include a screen only
to fill a slot.

## Required checks

- [ ] Exact App Store candidate Build 8; no mockups, splash-only or login-only art.
- [ ] Apple-accepted portrait size, preferably 1320×2868 or 1260×2736 for the 6.9-inch slot, with no alpha channel.
- [ ] Status bar, safe areas, shared header, dock and mini-player are visually clean.
- [ ] Text remains legible at App Store thumbnail size.
- [ ] No private email, payment detail, debug copy, preview data or fabricated activity.
- [ ] Appearance is intentional and internally consistent in the selected mode.
- [ ] Every visible artwork, avatar, event image and creator identity has a retrievable rights-register entry.
- [ ] Product-specific IAP review screenshots match the exact consumable/subscription and remain separate from optional promotional images.
- [ ] Every exported image is reopened and visually inspected before upload.
